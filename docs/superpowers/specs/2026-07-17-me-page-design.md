# 「我」页与组织编辑 · 设计说明

日期：2026-07-17  
状态：**决策备忘**（非权威）。产品正文以 `books/now-order` 为准；阅读器用顶栏「规则 / 界面」透镜分读。

## 背景

工作台需要一个明确的身份枢纽：「我是谁、当前在哪个组织、怎么切组织/账号」。旧方案把能力堆在顶栏头像下拉里，且缺少个人信息编辑、组织编辑与成员管理的归属页。移动端底栏已有「我」，需要对齐落地页。

## 目标

- 独立的 **「我」** 页作为身份与账号枢纽。
- **审批页保留**；「我」上用加入申请 card 做数量提示并跳转。
- **编辑组织**为独立页（不在「我」上弹窗改组织）。
- PC / 移动入口清晰、不重复堆叠。
- 文档上规则与界面页级成对，阅读器透镜一次只看一类。

## 非目标（本版不做）

- 实现代码 / 路由落地 / API 细节实现计划（产品应用侧暂缓）。
- 组织内角色升降、计费、通知偏好。
- 加入码重置或修改（加入码只读展示）。

## 入口

| 端 | 行为 |
| --- | --- |
| **PC** | 顶栏有头像。**悬停** → 薄 dropdown；**点击** → 进入「我」。 |
| **移动** | **无**顶栏头像；底栏 **「我」** → 进入「我」。 |

### PC 悬停 dropdown（薄）

- 当前上下文（个人或组织名）
- 快捷切换：个人身份 + 已加入组织
- 进入「我」
- 退出登录

## 「我」页

三 card + 底部退出登录 / 切换账号；加入申请 card 仅 OWNER/ADMIN；组织编辑跳独立页；个人信息用对话框。

## 「编辑组织」页

OWNER 改名；加入码只读；OWNER/ADMIN 移除成员；审批不在本页。
