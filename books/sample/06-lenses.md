本书顶栏的 **透镜树**（可多选）就是透镜：同一本书、在一棵树里按轴勾选维度节点，目录与翻页只展示当前选择下可见的页与小节。透镜由 `book.json` 的 `lenses` **数组**声明（每节点自带 `title`）。选中写入 URL query（如 `?read=scenario&read=impl`），刷新与分享可还原。

{#why}
## 为何需要透镜

两类读者、两类任务常描述同一主题，但心智不同。同坐标内容应写在**同一页**，用 contents 页项上的 `lenses` 标哪些小节属于哪个**叶子**维度；切换透镜只过滤小节，**不换页**。

维度可有层级：选中父节点 = 展示其下全部叶子内容的并集；也可多选若干同层叶/父，并集去重。**同一分支同时只能选一层**（父与子不可并存）；跨轴 / 不同分支互不影响。多轴时页要**同时**满足各轴归属才可见。

{#how}
## 怎么声明

在 `book.json` 用 `lenses: [...]` 声明轴树（顶层 = 轴，节点含 `id` / `title` / 可选 `children`），并在 `contents` 页项上用 `lenses` 挂**叶子**归属。页 frontmatter **只写** `id` / `title`（须与 manifest `id` 一致）。顶栏把各轴合成 **一棵** 选择树。轴标题写在配置里，代码不写死 `kind` / `audience`。

```json
{
  "lenses": [
    {
      "id": "read",
      "title": "读法",
      "children": [
        { "id": "scenario", "title": "场景" },
        { "id": "impl", "title": "实现" }
      ]
    }
  ],
  "contents": [
    { "id": "overview", "file": "01-overview.md" },
    {
      "id": "auth",
      "file": "identity/01-auth.md",
      "lenses": {
        "read": {
          "scenario": ["login", "register"],
          "impl": ["api", "db"]
        }
      }
    },
    {
      "id": "navigation",
      "file": "05-navigation.md",
      "lenses": { "read": { "scenario": true } }
    }
  ]
}
```

| 写法 | 含义 |
| --- | --- |
| 省略页项 `lenses` | 各轴选择下都**常显**（如概览） |
| `option: true`（叶子） | 整页属于该叶子，无小节过滤 |
| `option: ["sec-a", …]`（叶子） | 该叶子下只显示所列小节（含子级展开） |
| 页项 `lenses` 挂父节点 id | **禁止**；只允许叶子 |
| 顶栏选中父节点 | 生效 = 其下全部叶子并集 |
| 顶栏选中轴节点 | 生效 = 该轴全部叶子并集 |
| 顶栏同层多选 | 各选中节点展开后再并集（顶栏「多选」模式） |
| 顶栏单选 | 每轴最多一个节点（默认；顶栏「单选」模式） |
| 顶栏单页 / 汇总 / 尺子 | 单页按章阅读；汇总把当前透镜下各可见页小节拼成一篇；**尺子**（需 `book.json` 的 `ruler`）以钥匙小节为骨架，把 `links` 关联块挂到其下并按维度分组。**选「尺子」时维度可清空**，只看钥匙骨架、不挂维度块 |
| 同分支跨层 | 不允许；勾子取消父，勾父取消子 |
| 默认 | 每轴选中**第一个选项根**（如 `tenant` + `scenario`） |

约定：

- 透镜只过滤导航与小节显示，不改变标注键（仍是 `章节id#小节id`）；汇总 / 尺子模式同样复用该键。
- 节点 `id` 全书唯一、非空；每个透镜节点必须自带 `title`。
- 同坐标多维度写一页；已无 `correspondences`。
- 汇总模式下点左侧目录某页会切回「单页」并打开该页。
- 汇总模式不显示左侧书目录；右侧大纲按「组 → 页 → 小节」分层，组名/页名各只出现一次。

{#ruler}
## 尺子读法

相对透镜「在固定排版上过滤」，尺子是**另一种读法**：按关联表重组展示顺序。

```json
"ruler": {
  "axis": "read",
  "keys": "flow",
  "links": {
    "step-account": ["users-email-block"],
    "step-profile": ["users-phone-block"]
  }
}
```

| 字段 | 含义 |
| --- | --- |
| `axis` | 哪条透镜轴参与维度分组 |
| `keys` | 轴上哪个叶子（或子树）的小节可当尺子钥匙；省略则任意小节 id 都可 |
| `links` | 钥匙小节 id → 关联小节 id 列表（展示顺序 = 数组顺序） |

模块骨架页在 `contents` 上标 **`role: "ruler"`**（如 `index.md`）：只维护步骤键与 `rank`，维度正文仍分页并用 `links` 挂靠；单选维度时导航落到对应维度页，不把骨架当正文。见 [格式 · 清单](03-format.md#manifest-tree)。

同一张表的不同行组若挂到**不同**钥匙，**单页 / 汇总**读法下阅读器会自动在表首插入「尺子」列（填钥匙标题；同组用 rowspan 合并）。筛选/排序时会先拆开再合并，避免空格漏行。**尺子挂靠**下不插该列（内容已在钥匙标题下）。成书不必手写该列。

`{#id}` 有两种写法：独占行 = 块区间起点（可写 `rank=N`）；**表行尾** `{#id}` = 行组起点（到下一标记行前；无 id 行并入上一标记）。表头也可标 id，并挂到多个流程步（如列名 + 账号字段、列名 + 资料字段）。活样例见练习书 `users` 表。任意页可用 `rank` + 页 `showLevel` 控制详略（见 [格式 · 稳定 ID](03-format.md#stable-ids)）。
