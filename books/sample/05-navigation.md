{#paging}
## 目录与翻页

- 左侧目录点击章节切换页面；点击小节标题直接定位并高亮。
- 键盘 ← / → 或页面底部按钮翻到上一章 / 下一章。
- 有透镜时，←/→ 只走当前透镜可见的叶子页（见 [阅读透镜](06-lenses.md#how)）。

{#jump}
## 跳转与高亮

- 同章链接：平滑滚动并高亮目标小节。
- 跨章链接：应用内翻页并定位，不整页刷新。
- 试一试：[标记的四种状态](07-annotations.md#statuses)、[稳定 ID](03-format.md#stable-ids)。

{#expand-all}
## 展开细节

顶栏「展开全部细节」可一次展开本章所有折叠块；默认仍建议先读主干再按需展开。

{#export}
## 导出当前视图

顶栏「导出」把**当前勾选 + 透镜 + 尺子 + 内容过滤**组装成一份下载（与屏幕上看到的结构一致，不是原始单文件）。正文里引用了 `assets/` 图片时，得到的是 zip（Markdown + 这些图，相对路径仍可用）；没有图则仍是 `.md`。

同一份内容也可经 HTTP 拉取，方便 AI / 脚本按透镜取想要的切片，不必自己拼章节。见 [阅读透镜 · 导出接口](06-lenses.md#export-api)。
