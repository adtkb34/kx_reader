| 情况 | 表现 | 人接下来能做什么 | {#202608061170}
| --- | --- | --- | --- |
| 客户未命中 | 提示将随建单建档 | 补全姓名与联系方式后继续 |{#202608061122}
| 必填未选 / 描述为空或过长 | 字段红字或提示 | 补全或精简；过长改附件 | |
| 关联订单号不存在 | 「找不到该订单」 | 改单号或清空 | |
| 附件超限 / 类型不允许 | 上传失败 | 换文件或压缩 | |
| 提交失败 / 连点 | 错误条或按钮禁用；保留表单 | 重试；不产生半成品正式单 | |
| 中途关闭未存草稿 | 内容丢失 | 重填或从草稿续填 | |
| 无匹配责任组 | 留在待派单并告警 | 主管指定或补规则 |{#202608061125}
| 指派对象停用 | 字段错误 | 改选他人 | |
| 已被他人接单 | 提示并只读 | 关闭或申请转办 |{#202608061128}
| 响应 / 处理超时 | 顶栏标红；可继续写记录 | 优先处理或升级 | |
| 记录正文为空 / 对客含敏感信息 | 拦截 | 补正文或改内部备注 | |
| 误写记录 | 不允许改历史 | 追加更正并引用原记录 | |
| 转办给自己 / 对象停用 / 挂起无原因 | 提示错误 | 改选或补原因 | |
| 无方案就提请结案 / 重大单未升级 | 拦截 | 先补 plan/action 或升级 | |
| 通知失败 | 记录仍保存；标通知失败 | 重发或改渠道 | |
| 缺方案 / 执行或重大单未升级 | 拦截并列出缺失项 | 回处理补记录 |{#202608061131}
| 结案说明为空 / 驳回无原因 | 字段红字 | 补说明 | |
| 强制结案无权限 | 拒绝 | 找主管 | |
| 确认通知失败 | 仍待确认 | 重发或代操作（须写代操作记录） | |
| 关闭后想改结论 | 主档拒绝编辑 | 新单关联旧单，或主管授权重开（写 system 记录） |{#202608061134}
| 处理人离职仍有待确认单 | 主管接管 | 改派后继续 | |
| 工单已结案 | 主档只读；禁止改事实字段；仅质检可追加复盘备注 | — |{#202608061171}
| 重复投诉 | 可关联历史工单，但新建独立工单 | — | |
| 删除 | 只允许「作废」；记录与附件保留 | — | |
| 渠道原文 | 导入保留原文快照；编辑摘要不改原文 | — | |
| 正式提交前 | 不占工单号、不启动 SLA | — | |
| 网络失败 | 页内错误条，保留已填；可重试 | — | |

跨步骤约定：正式提交前不占工单号、不启动 SLA；结案后主档只读。校验失败停在当前步，已填内容尽量保留。
