## 权限

{#202608061161}
| 角色 | 能做什么 |
| --- | --- |
| 受理员 | 建单、编辑自己的草稿、查看自己创建的工单（对客记录） |
| 处理人 | 接单、写记录、转办 / 加签 / 挂起、提请结案 |
| 加签人 | 写记录；不可转办主责、不可独自结案 |
| 主管 | 改派、升级、强制结案、重开、导出、看组内全部含 internal |
| 质检 | 只读归档 + 复盘备注 |
| 客户 | 自助提交、看进度摘要、确认 / 驳回结案、评满意度 |

越权拒绝并写审计。
