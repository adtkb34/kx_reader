这一版只要能认出「谁的清单」和「只读共享给谁」。不做邀请码、不做多租户。

{#202608022181}
## 用户 `users`

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| 邮箱 `email` | 文本 | 必填，≤254，唯一 |
| 显示名 `display_name` | 文本 | 必填，≤64 |
| 密码哈希 `password_hash` | 文本 | 必填，隐藏 |
| 上次回顾 `last_review_at` | 时间 | 可空 |

| 可见性 | 规则 |
| --- | --- |
| 本人 | 本人可读写 |
| 默认 | 私有 |

`上次回顾` 给每周回顾用：三个计数仍从别的表现算，这里只记人何时做过回顾仪式。
