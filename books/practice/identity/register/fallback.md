## 异常

| 情况 | 表现 | 人接下来能做什么 | {#202608051488}
| --- | --- | --- | --- |
| 邮箱格式非法 / 已被占用 | 字段下红字；占用时提示「该邮箱已注册」 | 改邮箱，或去登录 |{#202608051452}
| 密码过短或不符规则 | 字段下说明规则（长度、字符） | 改密码后继续 | |
| 手机号格式非法 / 已被占用 | 字段下红字 | 改手机号 |{#202608051455}
| 用户名格式非法 / 已被占用 | 字段下红字 | 改用户名 | |
| 组织 ID 不存在 | 字段下「找不到该组织」 | 核对 ID，或改选创建组织 / 个人 |{#202608051458}
| 组织名称已被占用 | 字段下「名称已被使用」 | 换名称 | |
| 未选身份就点完成 | 提示必选一项 | 选出身份类型 | |
| 网络失败 / 服务超时 | 页内错误条，保留已填内容 | 重试提交，不必重填整表 |{#202608051437}
| 中途关闭页 | 已填内容不自动落库 | 下次从头注册；不建半成品用户 | |

跨步骤约定：提交成功前**不写用户行**。校验失败停在当前步，已通过的前序步骤内容保留在表单里。占用检查以提交时服务端结果为准，前端预检只是提前拦截明显错误。
