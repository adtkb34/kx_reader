{#20260810150801}
| 场景 | 操作 | 系统 |
| --- | --- | --- |
| 进入 | 打开工序管理 | 列出工序 |
| 新增 | 填写并提交 | 校验通过后建档 |
| 修改 | 点工序代码进入编辑（代码锁定） | 保存更新 |
| 删除 | 勾选后删除 | 执行删除 |

{#20260810142701}
| 场景 | 操作 | 系统 |
| --- | --- | --- |
| 进入 | 打开工艺流程 | 列出工艺 |
| 新增·从零 | 新增并编排提交 | 校验通过后建档 |
| 新增·基于已有 | 「基于此创建」进入编排 | 克隆后建档 |
| 修改 | 点工艺编号进入编辑（编号锁定） | 整单覆盖保存 |
| 删除 | 按工艺编号删除 | 整单移除 |
